A hands-on repository for learning, implementing, and experimenting with modern **Convolutional Neural Network (CNN)** architectures using PyTorch.

## 🎯 Goal

The main goal is to understand how CNN architectures evolve and how different design choices improve:

- Feature extraction
- Representation learning
- Computational efficiency
- Model depth and scalability
- Image classification performance

## 🧠 Architectures

The repository explores a range of CNN architectures, including:

- **LeNet** — Early CNN architecture
- **AlexNet** — Deep CNN breakthrough
- **VGG** — Simple and deeper CNN design
- **GoogLeNet / Inception** — Multi-scale feature extraction
- **ResNet** — Residual connections
- **DenseNet** — Dense feature connectivity
- **MobileNet** — Lightweight CNNs
- **EfficientNet** — Compound model scaling
- **ConvNeXt** — Modern CNN design inspired by Transformers

## 🛠️ Tech Stack

- Python
- PyTorch
- Torchvision
- NumPy
- Matplotlib

## 📚 Focus

This repository is primarily for **learning and experimentation**, with an emphasis on understanding the internal structure and design principles behind CNN architectures rather than simply using pretrained models.
